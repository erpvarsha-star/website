# Weekly Growth Rhythm — Scheduled Agents (created 23 Nov 2026)

Six recurring agents, all 09:00 IST, each with persistent state. Owner instruction: chief-of-staff weekly cadence per `PHASE4-PLAN.md`. `pending.md` is owned by the site-fix workstream — these agents do not touch it.

| Day | Agent | What it produces |
|---|---|---|
| Mon | KPI + site health | Banned-term gates on the 5 watch pages, og:image checks, blog count, KPI trend vs prior weeks, top-3 priorities |
| Tue | LinkedIn post 1 | Capability/thought-leadership post, 150–250 words, ready to paste + image brief |
| Wed | Lead-gen pipeline | 10 new qualified target companies, pipeline by stage, one outreach email variant (<120 words) |
| Thu | LinkedIn post 2 | Proof-led post (awards/quality/capability), complements Tuesday's post |
| Fri | GEO/SEO + competitors | AI-visibility probes (rotating query set), who ranks instead, one competitor teardown, 2 gap actions |
| Sat | Blog content engine | 900–1,300-word buyer-focused article draft (H1/H2/FAQ), parked for owner approval before publishing to the Wix blog |

## Guardrails baked into every agent
- Facts only from `FACTS.md`: closed-die hot forging 1–25 kg, presses 800–2,500 T, IATF 16949, RDSO only, Since 1989, 12,000+ MT/yr. No CIN, no machine counts, no warm/cold forging, no stainless, no aerospace.
- Lead-gen emails/phones are marked "verify via Apollo/Lusha" until the owner approves that spend (~$50–100/mo).
- Blog drafts are never auto-published — publishing happens in the main session after owner approval.

## State
Each agent keeps its own persistent directory (calendar, pipeline, visibility log, drafts). Runs are independent; state carries the memory.
